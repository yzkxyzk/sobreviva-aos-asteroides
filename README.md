# Sobreviva aos Asteroides

# Sobre o projeto

Sobreviva aos Asteroides é um jogo de sobrevivência desenvolvido no Scratch como parte da Semana 0 do curso CS50x de Harvard.
O objetivo é controlar uma nave espacial, desviar dos asteroides que a perseguem e sobreviver durante 30 segundos para vencer.

## 🎮 Funcionalidades

- Movimentação da nave utilizando as setas do teclado.
- Asteroides que perseguem o jogador.
- Sistema de clones para multiplicar os asteroides.
- Cronômetro de sobrevivência de 30 segundos.
- Tela de vitória (YOU WIN).
- Tela de derrota (GAME OVER).
- Efeitos sonoros durante o jogo.


## 🛠️ Tecnologias utilizadas

- Scratch 3.0: desenvolvimento do jogo com programação em blocos.
- Lógica de programação: utilização de condições, repetições, variáveis e eventos.
- Clonagem de sprites: criação de múltiplos asteroides durante a partida.
- GitHub: armazenamento e documentação do projeto.
